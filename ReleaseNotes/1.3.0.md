# 对讲机 1.3.0

- 接入 GitHub Releases 自动更新：自动检查、下载、签名校验，在应用内安装并重新启动。
- 原文和译文统一使用底部操作栏：左侧「字数 · 清空」，右侧「复制」。
- 移除原文右上角的剪贴板按钮，使用 Command-V 粘贴。
- 译文增加单独清空功能，保留原文；复制按钮在空白状态也保留位置，避免布局跳动。
- 保留清晰的翻译按钮禁用态，以及菜单栏中的置顶、快捷键和更新入口。

## 从 1.2.x 升级

在「设置 → 软件更新 → 版本发布地址」填写：

https://github.com/ifzeid/walkie-talkie/releases/latest/download/appcast.xml

保存后点击「检查更新」，即可在应用内升级，无需手动覆盖安装。1.3.0 已内置此地址，后续版本不再需要填写。

当前提供 Apple Silicon 构建，最低 macOS 13。应用使用本地 ad-hoc 代码签名，尚未进行 Apple 公证；更新 ZIP 使用既有 Ed25519 密钥签名。升级后如提示密钥迁移，在 API 编辑页重新填写密钥并保存，无需删除配置。
